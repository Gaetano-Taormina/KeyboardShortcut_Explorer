# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it privately:

1. Go to the repository's **Security** tab.
2. Click on **Advisories** and select **Report a vulnerability**.
3. Provide details, steps to reproduce, and impact.

Alternatively, you can contact the maintainer directly via GitHub issues labeled with `[Security]`. We appreciate your efforts to responsibly disclose findings and will respond promptly.
