# Contributing to KeyboardShortcut Explorer

First off, thank you for considering contributing to KeyboardShortcut Explorer! 🎉

## How Can I Contribute?

### Reporting Bugs

Before creating bug reports, please check existing issues to ensure it hasn't already been reported.

When creating a bug report, please include:
- A clear and descriptive title
- Steps to reproduce the behavior
- VS Code version and OS platform
- Expected vs actual behavior
- Screenshots or GIFs if applicable

### Suggesting Enhancements

Feature requests and improvements are always welcome! Please create an issue using the feature request template describing:
- The problem you want to solve
- The proposed solution or feature
- Any alternatives you've considered

### Pull Requests

1. Fork the repository and create your branch from `main`.
2. Install dependencies:
   ```bash
   pnpm install
   ```
3. Make your changes and test locally:
   ```bash
   pnpm run build
   pnpm run lint
   ```
4. Follow conventional commit messages (e.g. `feat: ...`, `fix: ...`, `chore: ...`).
5. Open a Pull Request with a clear description of the changes.

## Code of Conduct

This project adheres to the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.
